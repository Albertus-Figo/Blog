MY MEMOIR

My Coding Journey

My experience with coding started when my friend introduced me to the coding lesson programme he was taking and invited me to tag along. I wasn't sure at first, but when I had a trial class, I immediately fell in love with coding. And since that moment, I have continued learning how to code.

I started my coding journey with Python. It felt very easy at first, I solved the challenges my coding teacher gave me with no problem. 'Coding is easy' I thought, but that began to change when I continued to the Python Advanced programme. Python became more and more complex when I learned about more advanced data structures and algorithms. I had seriously underestimated how hard coding can be. Some of the challenges started taking much longer for me to solve, and there were times when I had no idea where to even begin. I had to spend more time thinking about the problem before I could finally find the solution.

This made me realize that coding is not that easy, it takes patience and problem-solving skills to master a programming language. And later on, when I started learning Java, I also realized that even though the language is different, the format used is still similar. This helped me quickly understand the basic concepts of Java, but more advanced Java concepts are still challenging. I still have a lot to learn, and I hope to continue improving my coding skills until I can become an expert.
